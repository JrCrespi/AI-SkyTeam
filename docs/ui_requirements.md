# Requisitos da interface (Etapa 12)

Decisões do João registradas antes da implementação da UI.

- **Visual próprio**: não reproduzir artes do jogo. Componentes (trilhas, painel, cartas) são desenhados do zero.
- **Tempo Real**: mostrar um cronômetro **sem números**, só uma indicação visual do tempo restante (barra ou arco
  que esvazia). Ao zerar, a UI envia a ação de tempo esgotado para a engine (P22).
