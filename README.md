# AI-SkyTeam

Implementação digital, determinística e orientada a dados das regras do board game **Sky Team**, em Python,
servindo tanto para jogar por interface gráfica quanto como ambiente de treino de agentes de IA.

A engine de regras é independente da interface. Nenhum asset comercial do jogo é reproduzido.

## Estado atual

Etapa 1 (análise das regras), feita a partir do manual base e do Registro de Voo. Ainda não há código.
